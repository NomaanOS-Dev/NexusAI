# NexusAI — Autonomous Local Vector & Ingestion Engine

NexusAI is a lightweight, zero-dependency local vector store and data ingestion pipeline tailored for air-gapped systems and low-resource environments.

---

## 🚀 Key Modules

- **`ingester.py`**: Handles document parsing, chunking, and preparation.
- **`vector_store.py`**: Pure-Python / NumPy-optimized similarity search and embedding storage.
- **`cli.py`**: Interactive command-line interface for managing data ingestion and queries.

---
